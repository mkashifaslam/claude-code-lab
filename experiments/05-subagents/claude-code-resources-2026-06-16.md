**Best practices:**
- Hooks are shell commands executing automatically at 12 lifecycle events: PreToolUse (approve/deny actions), PostToolUse (checks after changes), and others
- Three handler types: Command (shell), Prompt (single-turn LLM), Agent (subagents with tool access)
- Use for enforcing project rules, automating repetitive tasks, integrating with CI/CD (GitHub Actions, GitLab CI)
- Security: always review and test hooks before adding — they run arbitrary shell commands automatically
- Deployment workflow: compile TypeScript hooks, copy dist/ to `.claude/hooks/`, verify patterns
- Common use cases: format files post-edit, block commands before execution, send notifications, inject session context

### MCP Server Integrations

**Top repositories:**
- [**steipete/claude-code-mcp**](https://github.com/steipete/claude-code-mcp) (1,299 ⭐) — Claude Code as one-shot MCP server — pattern for "agent in your agent" composition. Updated 2026-05-15.

**Configuration & usage:**
- Claude Code connects to external tools via Model Context Protocol (MCP), an open standard
- Configuration: `~/.claude.json` and `.mcp.json` files; CLI management via `claude mcp add`
- Import Claude Desktop servers: `claude mcp add-from-claude-desktop`
- Each MCP server declares tools, inputs, outputs; Claude discovers at startup
- Common integrations: Notion, HubSpot, Gmail, Airtable, GitHub, Google Workspace (read email, Google Docs, Sheets queries)
- Result: Claude Code reads and acts on external systems directly instead of paste/ask pattern

## Community Insights

### Ecosystem Maturity (Q2 2026)

The Claude Code ecosystem has solidified around five core extension points: **skills** (slash commands with domain logic), **subagents** (isolated, task-focused AI assistants), **hooks** (lifecycle automation), **MCP servers** (external tool integrations), and **CLAUDE.md guidance** (persistent project context). The highest-signal repos (luongnv89/claude-howto at 37k stars, shanraisshan/claude-code-best-practice at 57k stars, ruvnet/ruflo at 59k) emphasize **real working examples over abstractions**. 

Most repos follow clear patterns: organize by topic (skills/, agents/, hooks/, mcp/) with structured file layouts, document copy-paste workflows, and include runnable examples. The shift from individual agent use to **multi-agent teams** (AWS samples, zircote orchestration, ruflo) is accelerating in production teams—file ownership, task serialization, and adaptive memory are now table stakes. Cost optimization (token budgets, context pruning) appears across newer best-practice repos, suggesting scaling pain points.

### Gaps & Opportunities

1. **Memory system patterns** — Only luongnv89/claude-howto references the auto-memory system in depth; most projects pre-date or underutilize Claude Code's persistent memory (.claude/projects/<name>/memory/). No dedicated repo for memory best practices or patterns yet.

2. **Security & compliance for agents** — Claude-BugHunter is security-focused but domain-specific (red-team). No general-purpose repo for OWASP-style agent security, rate limiting, token budging, or audit patterns.

3. **Testing & observability** — disler's multi-agent-observability is the outlier. Few repos test hooks, subagents, or MCP integrations. No shared testing frameworks or CI/CD patterns for validating agent outputs.

4. **Enterprise team workflows** — aws-samples and pedrohcgs show spec-driven approaches, but little on scaling multi-team, cross-project orchestration or managing shared agent libraries.

5. **Claude API & Agent SDK** — Anthropic's official Agent SDK and api.anthropic.com integration is underexplored in community repos. Opportunity for bridge patterns between claude-code-lab and backend automation.

### Standout Repos

- **luongnv89/claude-howto** & **shanraisshan/claude-code-best-practice** — Both are living documents, updated weekly, with high star counts. Best for learning current patterns.
- **FlorianBruniaux/claude-code-ultimate-guide** — Most comprehensive single resource; 255 templates + whitepapers give it edge for reference + teaching.
- **ruvnet/ruflo** — Highest star count; meta-harness pattern is production-proven and worth studying for multi-agent orchestration.
